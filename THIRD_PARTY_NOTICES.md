The Chromium notice inventory includes source components that may be unused
in these Linux binaries. Its [inventory](licenses/chromium/inventory.json)
records 1,134 source paths and hashes, checked against the fresh configured
Linux checkout and its pinned dependencies. It preserves the license texts;
it does not independently establish the exact binary dependency graph.
The accompanying [offline credits](licenses/chromium/about_credits.html) were
generated by Chromium's own Linux credits tool from that checkout. The
two rebuilds enable `generate_about_credits = true`; both compiled
credits files match the offline bundle byte for byte.

The declared Chromium revision is
`3bb54dbfa29e4506909fb9d289ad1a28ab76fceb` (158.0.8107.0).
Both Chromium packages were rebuilt from a fresh checkout of that revision.
Their [x86_64](docs/validation/chromium-build-x86_64.json) and
[ARM64](docs/validation/chromium-build-arm64.json) build records capture the
source dependencies, patch, GN arguments, toolchain and packaged hashes.
The patch and GN arguments are in
[`userland/chromium/patches`](userland/chromium/patches).

Application source is available from the
[pinned upstream tree](https://chromium.googlesource.com/chromium/src/+/3bb54dbfa29e4506909fb9d289ad1a28ab76fceb/)
and its `DEPS`. Follow the accompanying rebuild guide to synchronize those
exact dependencies and apply the project patch. FFmpeg's declared matching
source is also included as
[`ffmpeg-42a2a7a2.tar.gz`](third_party/sources/ffmpeg-42a2a7a2.tar.gz), from
[the upstream revision](https://chromium.googlesource.com/chromium/third_party/ffmpeg/+/42a2a7a2b2ceb0b1554af1e99a8cdaae189404bb/).
Generated configuration comments in this archive have workstation paths
removed; [the cleanup record](third_party/sources/ffmpeg-sanitization.json)
identifies the files and archive hashes. All 11,351 tracked entries were
checked against the fresh FFmpeg checkout. Only the 36 documented comment
lines differ; executable content and executable file modes match.
Its per-file terms apply. GPL files in that source snapshot do not establish
that GPL components were linked into Chromium.

The GN arguments set `is_component_ffmpeg = true`. To replace this LGPL
component, modify its source in the pinned checkout, rebuild the
`libffmpeg.so` target in the corresponding Chromium output directory, and
replace that library beside `chrome` while preserving its ABI. The browser
loads the library at runtime; this does not require relinking the browser.
See section 6 of the accompanying LGPL-2.1 text for the license terms.

Locally built kernels and initramfs images are excluded from the initial Git
distribution. When distributing those images later, accompany them with these
notices, exact kernel and BusyBox corresponding source, build configuration
and modifications, and corresponding sources for copied LGPL/GPL runtime
libraries. Preserve the host distribution's copyright files and source-package
versions. An upstream link alone is not a complete source-distribution plan.
The GNU project's [distribution guidance](https://www.gnu.org/licenses/gpl-faq.en.html#UnchangedJustBinary)
explains the obligations. Separate images do not remove them.
